# Исследование данных

Откройте `01_data_overview.ipynb`. В начале описаны основные сущности: товар, склад, география, продажа и остаток. Затем объяснено, почему для объединения таблиц нужен ключ дата × склад × артикул и как из этих сущностей получаются признаки для будущего прогноза.

Дальше ноутбук проверяет все строки: схему, пропуски, повторы, распределения чисел и категорий, изменение ассортимента и сочетания признаков. Только точечный график использует случайную выборку. Ограничение осей некоторых графиков не удаляет строки из расчётов. Подписи и краткие объяснения — на русском; технические имена исходных полей раскрыты рядом с сущностями.

После выполнения появляются дневные таблицы в `data/processed/`. PNG и небольшие таблицы записываются в `data/artifacts/research/`. Они нужны следующему разделу — `features/`. Основные наблюдения кратко собраны в [findings.md](findings.md).

## Проверка приёмов после базовой итерации

`02_trics.ipynb` запускается после основного FE. В нём проверяем длинную и событийную историю, вес свежих строк, более глубокий CatBoost, двухэтапную модель продажи/размера, обработку целочисленных прогнозов и смеси с простым средним. Для выбора настроек и подтверждения результата используются разные половины июня; июльские метки открываются после фиксации рецепта.

```bash
python scripts/run_notebooks.py research/02_trics.ipynb
```

Словарь дополнительных признаков — `features/TRICKS.md`. Результаты и графики — `data/artifacts/tricks/`, краткий вывод после выполнения — `research/tricks_results.md`. Модель и рецепт сохраняются в `data/models/tricks/`.


## Время, сезонность и сходство рядов

`03_time_analysis.ipynb` выполняется после первого обзора данных: ему нужны `sales_daily.parquet`, `stock_daily.parquet` и описание границ обучения, которое создаёт основной FE. В начале объясняется, почему общий рост может отражать расширение числа пар, а не сезонность. Отдельно рассматриваются все известные пары и фиксированный состав с начала 2024 года.

Внутри есть классическое разложение, устойчивый STL, MSTL с неделей/годом, недельные эффекты с блочной оценкой неопределённости, календарные годовые профили, ACF/PACF, спектр и диагностические тесты. Склады сравниваются по уровням, изменениям и DTW недельной формы; товары — по редкости продаж и недельным профилям. Необычные даты и кандидаты смены уровня изучаются без автоматического удаления.

Восемь прогнозных методов сравниваются на восьми границах с горизонтом 28 дней. Все границы и ответы лежат внутри старого обучения до 2026-06-05. Эти фиксированные прогнозы на 28 дней отличаются от однодневного обновляемого прогноза в `training/`.

```bash
source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_notebooks.py research/03_time_analysis.ipynb
```

Для интерактивной работы выберите Python из `.venv`; пакет `statsmodels` добавлен в зависимости. Результаты и версии окружения сохраняются в `data/artifacts/time_analysis/`, короткий отчёт автоматически обновляется в [time_analysis_results.md](time_analysis_results.md).
