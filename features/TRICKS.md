# Экспериментальные признаки для редких продаж

Эти десять признаков строит `research/02_trics.ipynb` поверх основной дневной панели. Они используются в исследовательских моделях этого ноутбука. В основной версии FE остаётся 50 входов; расширенная версия здесь содержит 60.

Сущность — пара склад × артикул. `t` — день прогноза; текущие продажи не входят ни в один расчёт. Недостающие дни после первого появления пары заполняются нулями по прежнему допущению. Новые метаданные товара и остатки в этих расчётах не используются.

| Имя в коде | Что означает | Как считаем |
|---|---|---|
| `tr_days_since_sale` | Время с последней продажи | Разница между датой t и последней датой положительных продаж строго до t. Если продаж ещё не было, пропуск. |
| `tr_sale_prob_28` | Сглаженная вероятность продажи | Экспоненциальное среднее индикатора положительных продаж до t−1, α = 2/29. Нулевые дни обновляют оценку. |
| `tr_positive_size_28` | Сглаженный размер положительной продажи | Экспоненциальное среднее положительных количеств до t−1, α = 2/29. Обновляется только при продаже; остальные дни несут прежнюю оценку. |
| `tr_tsb_mean_28` | Средний объём для редких продаж | Произведение сглаженной вероятности и сглаженного положительного размера. При отсутствии истории — 0. |
| `tr_qty_mean_56` | Длинный уровень продаж | Среднее за предыдущие 56 календарных дней. |
| `tr_sale_share_56` | Частота продаж отдельно от размера | Доля дней с положительными продажами за предыдущие 56 дней. |
| `tr_qty_mean_90` | Более длинный уровень продаж | Среднее за предыдущие 90 календарных дней. |
| `tr_qty_median_28` | Простой прогноз медианы | Медиана количеств за предыдущие 28 календарных дней. |
| `tr_same_weekday_mean_4` | Недельная привычка пары | Среднее количеств на предыдущих четырёх таких днях недели: t−7, t−14, t−21, t−28. |
| `tr_same_weekday_median_4` | Медиана недельной привычки | Медиана тех же четырёх прошлых дней недели. |

Если полное окно ещё не набралось, используется доступная прошлая часть. Суффикс 28 у сглаживания задаёт коэффициент α, а не жёсткое календарное окно. Для положительного размера отсчёт идёт по событиям продаж, а не по всем дням. Эти свойства важны для интерпретации редких товаров.

Раздельное обновление вероятности и размера соответствует идее TSB — метода прогноза прерывистого спроса Teunter–Syntetos–Babai. Его произведение оценивает среднее, а не медиану. Поэтому хороший прогноз по RMSE не обязан выигрывать по MAE.

В ноутбуке проверяем недельный сдвиг независимым расчётом и меняем будущие количества, чтобы убедиться: ранее рассчитанные признаки от будущего не зависят. Сводная статистика сохраняется в `data/artifacts/tricks/extra_feature_profile.csv`.
