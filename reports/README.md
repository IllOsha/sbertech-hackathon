# Отчёт нулевой итерации

Откройте [iteration_00.html](iteration_00.html) в браузере. Это один автономный файл: графики, агрегаты и Plotly встроены, интернет и Jupyter для просмотра не нужны. GitHub показывает HTML как исходный код; скачайте файл и откройте локально.

Для пересылки достаточно этого `.html`: другие папки, CSV, Python и локальный сервер получателю не нужны. Кнопка «Скачать HTML» в шапке сохраняет готовый файл под именем `sbertech-iteration-00.html`. Получатель скачивает вложение и открывает его в обычном браузере (Chrome, Edge, Firefox или Safari). Предпросмотр вложений в мессенджере или почте может отключать JavaScript — используйте открытие скачанного файла в браузере. Интернет нужен только для перехода по дополнительным ссылкам на GitHub.

Внутри — задача и сущности, ограничения данных, время и сезонность, словарь с распределениями всех 50 основных признаков и цели, парные сравнения моделей, экспериментальные приёмы и галерея всех сохранённых PNG.

Распределения построены по всем строкам сохранённых выборок обучения, валидации и теста. Границы числовых интервалов общие для периодов; ограниченный диапазон определяется квантилями обучения. Под графиком указаны скрытые значения, статистики учитывают полную выборку. Категории выбираются по частоте в обучении. Пропуски числовых полей не входят в столбцы, знаменатель долей — все строки своего периода.

## Как обновить

Из корня проекта, в подготовленном окружении:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/build_report.py
```

Сборщик читает результаты из `data/artifacts/` и локальные `data/processed/train.parquet`, `valid.parquet`, `test.parquet`. Они должны быть созданы ноутбуками обзора и признаков. Сборщик не запускает ноутбуки и не переобучает модели. Шаблон — `scripts/report_template.html`.

Отчёт содержит дату сборки, исходный коммит и SHA256 файлов, использованных при сборке. Список можно скачать в разделе «Источники и воспроизводимость». Если исходные результаты изменились, пересоберите HTML. Из исходных таблиц в отчёт попадают только агрегаты; веса моделей и строки исходных выборок не включены.

Для каждой диаграммы доступны подсказки, скрытие серий через легенду и сохранение PNG. Распределение выбранного признака можно скачать как CSV, исходные изображения — открыть крупно и сохранить. «Печать / PDF» сохраняет текущие состояния интерактивных диаграмм; для полного просмотра галереи используйте HTML.
