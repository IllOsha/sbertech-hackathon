# Данные и результаты расчётов

| Папка | Содержимое | В Git |
|---|---|---|
| `artifacts/research/` | Качество исходников, распределения, дневные сводки | Да |
| `artifacts/features/` | Словарь, описание выборок и графики признаков | Да |
| `artifacts/training/` | Метрики, параметры, коэффициенты и сравнения моделей | Да |
| `artifacts/tricks/` | Результаты дополнительных приёмов и выбранный рецепт | Да |
| `artifacts/time_analysis/` | Декомпозиции, сезонность и сравнения временных прогнозов | Да |
| `processed/` | Дневные Parquet, общие выборки и прогнозы по строкам | Нет |
| `models/` | Веса моделей и обученные преобразования | Нет |

`artifacts/` содержит компактные результаты для просмотра коллегами. В корне этой папки также находятся описание исходников с SHA256 и сохранённая сводка проверки прогона. JSON с проверками описывает выполненный расчёт; он не запускает проверку заново.

`processed/` создаётся обзором данных и построением признаков, `models/` — обучающими ноутбуками. Для восстановления используйте порядок из [README проекта](../README.md). Перезапуск обновляет файлы; отчёты в Git относятся к последнему сохранённому прогону.

Исходные CSV размещаются отдельно в [docs/datasets/](../docs/datasets/README.md).
