# Исходные данные

Получите архив `hakaton.zip` у команды или организаторов и распакуйте сюда:

- `sales_dataset_hakaton_train.csv` — продажи;
- `stock_dataset_hakaton_train.csv` — остатки.

Сохраняйте исходные имена и содержимое файлов. Публичная ссылка на скачивание пока не предоставлена. CSV и любые другие файлы в этой папке, кроме этой памятки, исключены из Git: исходники занимают около 528 МиБ.

Размеры и SHA256 исходников записаны в [data_sources.json](../../data/artifacts/data_sources.json). Описание таблиц — в [docs/README.md](../README.md), порядок расчёта — в [корневом README](../../README.md).
