# Материалы хакатона

`datasets/` содержит исходные CSV из `hakaton.zip`:

- `sales_dataset_hakaton_train.csv`: 1 492 370 строк продаж, 2024-01-01 — 2026-07-31;
- `stock_dataset_hakaton_train.csv`: 6 153 988 строк остатков, 2023-12-13 — 2026-07-31.

Эти большие файлы исключены из Git. Для повторного запуска положите их сюда с исходными именами. Официальные описание задачи, горизонт прогноза и метрика пока не предоставлены.

Пояснение сущностей и анализ находятся в [research/](../research/README.md), словарь признаков — в [features/FEATURES.md](../features/FEATURES.md), обучение и результаты — в [training/](../training/README.md). Графики и небольшие CSV лежат в `data/artifacts/` от корня проекта.
